# Sales Data Analysis Project

## Overview
In this project, I analyzed a sales dataset to understand product performance and monthly sales trends. The goal was to derive useful business insights using Python.

## Tools Used
- Python
- Pandas
- Matplotlib

## Key Analysis Performed
- Data cleaning and preprocessing
- Monthly sales trend analysis
- Top-performing product identification
- Data visualization using graphs

## Insights
- Sales vary across different months, indicating seasonal demand
- Certain products contribute more to overall revenue
- The analysis helps in business decision-making like inventory planning

## Files Included
- sales_analysis.ipynb → VS Code with full analysis
- cleaned_sales_data.csv → Processed dataset (optional)

## Conclusion
This project demonstrates basic data analysis workflow including data handling, visualization, and insight generation.
